# Now Known

A simple static daily reading journal for GitHub Pages.

## Update the site

1. Open `index.html`.
2. Find the comment beginning `Add a new article`.
3. Copy the example `<article class="entry">` block.
4. Paste it below the newest entry and edit the date, highlight, source, and note.
5. Commit and push the changes to GitHub. GitHub Pages will publish the update.

## GitHub Pages setup

Create a repository, upload these files to the default branch, then open **Settings → Pages**. Choose **Deploy from a branch**, select the default branch and the `/ (root)` folder, then save.

If the repository is named `username.github.io`, the site will be available at `https://username.github.io/`. For a project repository, it will usually be `https://username.github.io/repository-name/`.
